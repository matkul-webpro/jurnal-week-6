1. JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis, seperti menangani klik tombol, memvalidasi formulir, dan memperbarui konten tanpa memuat ulang halaman.

2. jQuery adalah library JavaScript yang mempermudah penulisan kode JavaScript, terutama untuk memanipulasi elemen HTML, menangani event, membuat animasi, dan melakukan permintaan AJAX.

3. Perbedaan JavaScript dan jQuery terletak pada cara penggunaannya. JavaScript merupakan bahasa pemrograman, sedangkan jQuery adalah library yang dibangun menggunakan JavaScript. JavaScript dapat digunakan secara langsung tanpa library tambahan, tetapi jQuery memerlukan library yang harus disertakan pada halaman web. jQuery menyediakan sintaks yang lebih sederhana untuk tugas tertentu, seperti memilih elemen HTML dan menangani event, sedangkan JavaScript memiliki fitur yang lebih luas dan dapat digunakan tanpa ketergantungan pada library tambahan.
